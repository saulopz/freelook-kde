# Go fonts

The Go font family, created by the Bigelow & Holmes type foundry (the
designers of Lucida, the typeface of OpenWindows) for the Go project.
FreeLook uses it as a free relative of the OpenWindows look.

- Source: https://go.googlesource.com/image (folder `font/gofont/ttfs`)
- More: https://go.dev/blog/go-fonts
- License: BSD 3-Clause, in [LICENSE](LICENSE). Copyright (c) 2016 Bigelow & Holmes Inc.

The files are included unchanged. `install.sh` copies them to
`~/.local/share/fonts/FreeLook/`.
